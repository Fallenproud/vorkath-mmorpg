# Engine model guidance
- GLB meshes exported using trimesh, flat vertex colors, without custom material textures, skeletal rigs, LOD or collision primitives.
- These are genuinely importable 3D geometry prototypes, **not** final production-quality organic assets.
- Inspect orientation, scale, topology, shading and collisions in target engine.
- Vorkath world archive contains `.vptile` terrain specification, but this package does not include runnable terrain engine code.
- If using Blender / Higgsfield 3D MCP for upgraded hero-quality assets, preserve imported sources and keep generated candidates `PROPOSED` pending visual QA.
